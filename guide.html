방법 1: GitHub Pages 추천
1
GitHub 계정 생성
github.com 접속 → Sign up (이미 있으면 건너뛰기)
2
새 저장소(Repository) 생성
우측 상단 + → New repository → 이름: fire-safety → Public 선택 → Create
3
파일 업로드
uploading an existing file 클릭 → index.html과 guide.html 파일을 드래그앤드롭 → Commit changes
4
GitHub Pages 활성화
Settings → Pages → Source: Deploy from a branch → Branch: main / /(root) → Save
5
접속 확인 (1~2분 후)
https://[계정이름].github.io/fire-safety/
https://[계정이름].github.io/fire-safety/guide.html
⚡
방법 2: Netlify Drop 가장 쉬움
1
Netlify Drop 접속
app.netlify.com/drop 접속
2
폴더 드래그앤드롭
index.html과 guide.html이 들어있는 폴더를 브라우저 화면에 드래그앤드롭
3
배포 완료!
https://랜덤이름.netlify.app
💡 팁: 로그인하면 Site settings → Change site name에서 URL을 원하는 이름으로 변경할 수 있습니다.
🚀
방법 3: Vercel 개발자 추천
1
Vercel 회원가입
vercel.com 접속 → GitHub 계정으로 연동 가능
2
프로젝트 업로드 & 배포
New Project → Upload → 파일 업로드 → Deploy
3
배포 완료!
https://프로젝트이름.vercel.app

개선보고 링크 공유 방법

배포 후 담당자에게 보내는 개선보고 링크 형식:

https://[배포된URL]/?report=F-0001

예시:

https://myname.github.io/fire-safety/?report=F-0001
ℹ️ 전달 방법: 카카오톡, 문자, 이메일 등으로 링크를 그대로 전달하세요. 담당자가 링크를 열면 해당 관리번호가 자동 선택됩니다.
💾
데이터 관리 주의사항

현재 저장 방식

  • 데이터는 각 브라우저의 localStorage에 저장됩니다
  • 같은 기기 + 같은 브라우저에서만 데이터가 유지됩니다

데이터 백업 방법

  • 관리대장 화면의 📥 데이터 내보내기 버튼으로 JSON 파일 백업
  • 📤 데이터 가져오기 버튼으로 복원 가능

여러 기기에서 사용하려면

1
기기 A에서 "데이터 내보내기"
2
JSON 파일을 기기 B로 전송 (카톡, 이메일 등)
3
기기 B에서 "데이터 가져오기"
⚠️ 주의: 브라우저 캐시를 삭제하면 데이터가 사라집니다. 정기적으로 데이터 내보내기를 해두세요.
